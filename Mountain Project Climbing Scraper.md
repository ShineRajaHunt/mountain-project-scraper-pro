## 🛠 Feature Breakdown

### Feature 1 — Route Parsing
Extract route names, grades, types, and star ratings.

### Feature 2 — Area Crawling
Walk the area tree from state to crag to sector.

### Feature 3 — Polite Rate Limits
Respect `robots.txt` and add configurable delays.

### Feature 4 — Grade Normalization
Convert YDS, V-scale, and French grades into a unified schema.

### Feature 5 — GeoJSON Export
Emit coordinates for maps and GIS tools.

### Feature 6 — Scheduled Refresh
Run the scraper on a cron or Docker schedule.
